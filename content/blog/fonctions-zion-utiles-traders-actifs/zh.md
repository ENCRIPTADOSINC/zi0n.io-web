## 移动端活跃交易者面临的核心安全威胁

活跃交易者每天都需要频繁调用 API 密钥、登录中心化交易所（CEX）、交互去中心化金融（DeFi）智能合约以及确认非托管钱包签名。恶意攻击者专门针对移动环境开发了多种攻击手段：

- **屏幕监控与剪贴板地址劫持：** 隐蔽的恶意软件在后台持续监控显示缓冲区，窃取两步验证（2FA）动态密码，并在交易者复制粘贴钱包哈希值时，悄无声息地篡改提币目标地址。
- **针对性的 SIM 劫持（SIM Swapping）：** 犯罪分子利用社会工程学手段欺骗电信运营商客服，非法补办交易者的手机号，从而截获各大交易所的短信登录验证码。
- **真实 IP 追踪与定向拒绝服务攻击（DDoS）：** 在向区块链 RPC 节点或撮合引擎发送请求时泄露真实 IP 地址，不仅会暴露交易者的地理位置，还会让对手方在行情剧烈波动的关键点发动网络攻击阻断连接。
- **公共充电桩物理数据提取（Juice Jacking）：** 在机场或行业会议使用不受信任的 USB 充电端口时，攻击设备会利用数据传输针脚尝试绕过系统防线读取设备存储。
- **线下物理胁迫与暴力抢劫：** 在商务出差或行业交流活动中，交易者一旦在人身安全受威胁时被迫解锁手机，其全部加密资产与持仓便会直接展现在歹徒面前。
